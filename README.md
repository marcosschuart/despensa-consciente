# Despensa Consciente

Aplicação web em **React (Vite)** para controlar a validade dos alimentos de casa e reduzir o desperdício.
Trabalho A03 – Desenvolvimento Web (Prof. Daniel Paiva).

**ODS relacionada:** ODS 12 – Consumo e Produção Responsáveis (meta 12.3: reduzir o desperdício de alimentos).

## Funcionalidades

- Cadastro de alimentos com nome, quantidade e validade
- Ordenação automática por urgência, com cores e selos de status
- Filtro por status (vencido, use já, atenção, tranquilo)
- Alerta com os itens em risco
- Dicas de aproveitamento por tipo de alimento
- Dados salvos no navegador (localStorage)

## Como executar

```bash
npm install
npm run dev
```

Para gerar a versão de produção: `npm run build`.

## Tecnologia

React 18 + Vite 5.
